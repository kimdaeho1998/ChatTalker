# Release Checklist

- [ ] Owner-approved requirements/work orders/decisions
- [ ] Compatibility matrix and dependency/security review completed
- [ ] No secrets in source; environment/secret plan approved
- [ ] Migration, backup, restore and rollback rehearsed in non-production
- [ ] API/DB/WebSocket compatibility review completed
- [ ] Required acceptance, regression, security and performance evidence attached
- [ ] Monitoring, audit, alerting and incident ownership documented
- [ ] Windows packaging/update/notification policy approved
- [ ] Git status/diff reviewed; commit/push/deploy authorization explicitly granted

Release is prohibited while any required item is unverified, blocked, or unapproved.
